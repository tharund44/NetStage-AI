# Topology Documentation

R1 (10.10.10.1) is the DHCP server for all VLANs. MLS1 is an L3 switch with SVIs. VLAN 10 PCs are on the same subnet as R1. VLAN 40 PCs are on a different subnet behind MLS1's SVI Vlan40 (10.10.40.1).

*Note: Please consult the .pkt file for exact device names and interfaces.*
